# Опечатка в Псалме 17:2

> Псалом 17:2 «Возлюблю тебя, Господи, крепость моя!» — слово «тебя» напечатано со строчной буквы, должно быть с заглавной.
>
> Степан (тикет 279544, help.only.bible)

В печатных изданиях (РБО и МП) в этом месте «тебя» со строчной буквы.

Однако во всех остальных местах Псалтири сочетание «Тебя, Господи» напечатано с заглавной — 16 мест:
Пс 9:11, 17:50, 29:2, 30:2, 30:15, 37:16, 56:10, 61:13, 68:7, 70:1, 78:12, 85:12, 107:4, 137:4, 138:21, 144:10.
Пс 17:2 — единственное место со строчной.

Принято решение исправить для единообразия: «тебя» → «Тебя».

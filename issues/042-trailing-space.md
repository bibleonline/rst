# Хвостовой пробел во Второзаконии 4:46

Найдено автоматической проверкой пробельных артефактов по parsed78.

Во Втор 4:46 после завершающей точки перед переводом строки стоит лишний пробел:

```
#4:46#...по исшествии их из Египта. \n
```

Единственное такое место на весь текст. На отображение не влияет, убираем для чистоты данных.

# make-usfm — генератор `parsed → usfm`

Собирает выгрузки USFM всех составов и `BookNames.xml` к каждому. Запуск —
целью `make usfm` из корня репозитория.

```
parsed66/ ─┐
parsed78/ ─┼─ make-usfm.pl ─▶ usfm/rst66/, usfm/rst78/, usfm/rst81/
parsed81/ ─┘                     + BookNames.xml в каждом
```

Прогон идемпотентен: результат сначала пишется во временный `usfm2/`,
сравнивается с текущим `usfm/` целиком, и файл переносится только если
изменился. Временный каталог удаляется в конце.

Сравнение включает первую строку (`\id`), поэтому правка `conf/usfm-codes.yaml`
доезжает до выгрузки, а испорченный вручную `\id` восстанавливается сборкой.

## Файлы каталога

- `make-usfm.pl` — сам генератор, цикл по составам
- `usfm.yaml` — титульные маркеры USFM по книгам (`mt1`/`mt2` и пр.)
- `alt.yaml` — правила альтернативной нумерации `\va`: по книгам диапазон
  печатных стихов и дельта до 66-й нумерации, `*` — стих без 66-го номера.
  В `rst81` Даниила нет: вставка 3:24–90 вынесена отдельной книгой
- `notes66.yaml`, `notes78.yaml`, `notes81.yaml` — выборка примечаний для
  каждого состава: по стиху указано, какое издание брать (опционально
  `/якорное слово`)

## Что читает из репозитория

- `conf/booknames.yaml` — русские титулы книг (`abbr`/`name`/`long`)
- `conf/usfm-codes.yaml` — USFM-коды по слагу книги
- `conf/paper-notes.yaml` — тексты примечаний печатных изданий
- `conf/redletter.yaml` — слова Христа (красные буквы)
- `parsed66/`, `parsed78/`, `parsed81/` — исходные `.dat`
